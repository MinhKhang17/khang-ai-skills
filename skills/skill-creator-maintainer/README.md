# Skill Creator & Maintainer

Meta-skill để tạo và bảo trì reusable AI skills trong `khang-ai-skills`.

Core change set:
1. `skills/<skill>/SKILL.md`
2. root `manifest.yaml`
3. root `README.md`

`SKILL_INDEX.md` là registry companion bắt buộc trong repository hiện tại.

Mọi thay đổi phải có Change Report gồm:
- file;
- action;
- section/anchor;
- line range;
- version impact;
- reason;
- dependency impact;
- apply order.
